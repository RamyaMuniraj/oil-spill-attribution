# Oil Spill Attribution MVP

## Aim
Detect a probable oil slick in a Sentinel-1 SAR scene, correlate it with AIS vessel tracks, and rank possible source vessels with explainable evidence.

## Development path
1. Load and display a SAR scene.
2. Extract possible dark slick regions using a transparent baseline method.
3. Plot matching AIS vessel tracks.
4. Rank vessels by location, time, vessel type, and AIS anomalies.
5. Add a simple reverse-drift estimate and dashboard.

## Folder guide
- `data/raw/`: downloaded source data; do not edit.
- `data/processed/`: cleaned/intermediate data.
- `notebooks/`: small exploratory notebooks.
- `src/`: reusable Python code.
- `outputs/`: charts, maps, and demo reports generated by the project.

## First checkpoint
Run `python src/check_environment.py`. It should print the Python version and confirm the core libraries are available.
